## Authorized outer-world import (0.3.3)

The outer-world implementation and data are reconstructed from `googology-dimension-1.0.0.jar`, SHA-256 `5310b51a48821bc49bb754068b04d89c787806679fd36303ca16a282af9f2fb4`. Its `fabric.mod.json` credits **Googology Dimension Team** and declares **MIT**. The supplied archive contains no separate copyright/license text; that fact is recorded rather than inventing a donor notice. On 2026-10-05 the project owner reported direct author permission to import its contents and material/equipment artwork. Imported portions retain their attribution and declared MIT status; the GPL terms above cover this project's own implementation and integration, not an assertion of exclusive ownership over donor material.

Imported source is under `ports/common/{main,client}/dev/guogaology/outer` and version-specific `outer` adapters. Original world-generation data and 61 templates are preserved under `content/outer-1.0.0`; all runtime imported assets use the shared `guogaology` namespace. Authorized mineral/gear textures replace their corresponding shared assets. The manifest records the exact aliases. No donor JAR, Minecraft class file or launcher credentials are redistributed in the source repository. API adapters call the installed game's algorithms; compatibility noise configurations are snapshots of the matching game's built-in worldgen data, not game binaries. See `docs/OUTER-IMPORT.md` for reproduction limits.
