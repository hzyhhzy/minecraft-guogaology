# 八巨构内饰逐类审计（0.5.6）

恢复基准是0.5.4.1的完整家具与标本柜，而不是0.5.5撤去旧柜后的版本。旧“50个晶核/晶体”计数在此只用于重建原陈列柜的形状和数量，不决定实际奖励，也不挑选普通家具替换成晶核。每种模型的原料选择由固定规则指定；晶核只来自下述专门装置与演奏桌，没有随机抽取。
