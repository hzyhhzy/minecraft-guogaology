# 生存引导进度 · 0.5.11

使用原版进度系统，保留原版各页与配方解锁。“果糕逻辑”是自动完成的目录根，首次进入三层世界的说明包含造门方法；返程门仍记录亲手激活。首次Ω矿物是里界的引导前置，不锁定传送。

八条主题分枝分别从七个里界群系和地府维度开始；每枝为代表材料→一级→二级→三级晶核，以及独立的进入巨构路线。晶核名称侧重能力，获得后仍须镶嵌才产生效果。巨构按进入实际建筑空间判定，无需开箱。另有吃果糕、弹奏紫菜桌与38槽Ω满配进度。父子关系用于引导，不强制完成顺序，不发额外物品。
