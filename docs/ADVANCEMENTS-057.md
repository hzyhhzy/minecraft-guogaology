# 生存引导进度 · 0.5.7

使用原版进度系统，原版各页与配方解锁不替换。首次登录即显示本模组页；门户节点按实际成功的投掷激活归属到投掷者。其他节点按获得材料、跨维度或真正开启巨构奖励箱触发，不要求严格顺序，也不发额外物品。

| ID | 名称 | 引导与完成条件 |
|---|---|---|
| `arrival` | 展开开始 | 从蛋糕与苹果出发，探索表界、里界和果糕地府。 |
| `guide/portal_outer` | 第一道门 | 用12个蛋糕在水平面摆出5×5去四角的门框，向内投入一个苹果。 |
| `guide/enter_outer` | 走进表界 | 穿过蛋糕门；在表界采矿、收集材料，并为下一层作准备。 |
| `guide/first_ore` | 序矿初采 | 用铁镐或更好的镐获得任一种序数矿物；四种矿都直接掉落材料。 |
| `guide/first_tool` | 手中的序数 | 制作或获得一把序数镐、剑或弓。 |
| `guide/first_book` | 随身手稿 | 制作扽西手稿。副手持有时，可从背包里的手稿按钮打开镶嵌界面。 |
| `guide/full_set` | 备齐护甲 | 备齐头盔、胸甲、护腿与靴子，可以混用四种序数材料。 |
| `guide/number_tools` | 数字也能成器 | 用数字刻石制作数字石镐或数字石剑；等级取材料数字的平均值向下取整。 |
| `guide/return_ready` | 出发，也要能回来 | 备好归途签和归途框。12个同种归途框搭门，投入归途签可返回上一层。 |
| `guide/portal_return` | 搭好归途 | 亲手投入归途签，激活任一种归途门。 |
| `guide/return_home` | 回到主世界 | 从表界返回主世界。 |
| `guide/return_up` | 返回上一层 | 从里界返回表界，或从果糕地府返回里界。 |
| `guide/portal_inner` | 矿物作门 | 用12个ω、ε、Γ、Ω结晶块搭水平门框，可混搭；投入一份Ω材料激活。 |
| `guide/enter_inner` | 走进里界 | 进入里界。晶核来自群系原料合成，序数晶体来自序数晶矿。 |
| `guide/raw_material` | 寻找群系原料 | 从自然景物中收集一种本地晶核原料。成品晶核不在野外直接生成。 |
| `guide/shards` | 晶矿的碎片 | 开采序数晶矿，获得序数晶屑；徒手也能采集，镐更快。 |
| `guide/crystal` | 稳定的一块 | 四片晶屑合成序数晶体，也能拆回。放置后稳定周围两圈的LHO材料。 |
| `guide/first_core` | 第一颗晶核 | 获得一颗晶核。区域晶核由多种群系原料合成；序数晶核由序数晶体逐级融合。 |
| `guide/station` | 强化台 | 制作强化台，可装入或取回晶核；装备附魔和晶核镶嵌互斥。 |
| `guide/socketed` | 镶入一枚 | 完成一次带晶核的装备或手稿编辑并关闭界面。 |
| `guide/higher_station` | 更高的强化 | 制作高级强化台，使用二阶晶核。 |
| `guide/ultimate_station` | 终极强化 | 制作终极强化台，使用三阶晶核。 |
| `guide/core2` | 二阶融合 | 用8颗同系一级晶核和1颗一级序数晶核，合成一颗二级晶核。 |
| `guide/core3` | 三阶融合 | 用8颗同系二级晶核和1颗二级序数晶核，合成一颗三级晶核。 |
| `guide/ordinal3` | 序数的凝聚 | 序数晶体与序数晶核逐级九合一，获得三级序数晶核；各级均可拆分。 |
| `guide/lamp_shaper` | 表情塑形 | 制作果糕灯塑形台，在两种表情、完整灯与3×3×3分块之间转换。 |
| `guide/compute_setup` | 自己的算力 | 收集算力芯片，制作机柜或终端。 |
| `guide/portal_underworld` | 果糕作门 | 在里界用12个果糕方块搭水平门框，再投入1个果糕方块激活。 |
| `guide/enter_underworld` | 进入果糕地府 | 进入果糕地府，探索冥林、错层、静沼与降链洞域。 |
| `guide/landmark_first` | 巨构初探 | 在任意巨构中开启第一只奖励箱，继续探索楼层和主题陈列。 |
| `guide/landmark_matrix` | 探索矩阵折峰堡 | 在矩阵折峰堡中开启一只主箱或副箱。 |
| `guide/landmark_power` | 探索迭代圆木塔 | 在迭代圆木塔中开启一只主箱或副箱。 |
| `guide/landmark_hydra` | 探索六枝冠庭 | 在六枝冠庭中开启一只主箱或副箱。 |
| `guide/landmark_absence` | 探索缺页悬空回廊 | 在缺页悬空回廊中开启一只主箱或副箱。 |
| `guide/landmark_weaver` | 探索紫菜三角宫 | 在紫菜三角宫中开启一只主箱或副箱。 |
| `guide/landmark_astra` | 探索Astra 推演中枢 | 在Astra 推演中枢中开启一只主箱或副箱。 |
| `guide/landmark_frontier` | 探索界限演算庭 | 在界限演算庭中开启一只主箱或副箱。 |
| `guide/landmark_guogao` | 探索果糕终境巨树 | 在果糕终境巨树中开启一只主箱或副箱。 |
| `guide/landmarks_all` | 八种巨构 | 探索八种巨构，并在每一种中开启至少一只奖励箱。 |
