- [x] 采样高崖供给，调整整件选址与实际生成密度；不以小链或低崖链补足数量。
- [x] 两端真实锚固、链体露空且交扣，邻链避让；保留巨构保护、封底、水域和整株植被避让。

## 高崖供给

旧地形三种子各16.78km²的高崖候选采样中，Y250～314高台约占2.1%～2.3%，几乎全部为冥林。仅提高生成概率不足以满足巨链密度。因此抬高错层群系的天然台顶至约255～300，保留原裂谷走向、错层台阶、水系与群系过渡；链条仍按真实地形选址，不为每条链凭空造山。

旧地下洞域回归通过；里界25,662个地形取样与1,082个天然大湖的位置／湖床指纹和0.4.5基线完全相同。检查记录：`build/049-terrain-regression.log`。

## 最终选址规则

48格网格，每格32个候选位置、16个方向。上端Y250～314，落差至少180格，水平跨度25～160格，下端为不高于Y60的真实谷底。上端中心锚栓深入岩层5格、锚座至少5/9底部岩点承力；下端锚座9/9底部支撑。首环的12格连接段可嵌入崖唇，中心线从4格后开始逐米检查露空，12格之后主体逐体素检查露空。

相邻原始候选按种子优先级一次判定，不递归查询已接受链条；上锚间隔至少32格、完整轴段间距至少11格，保留中空尖头链环交扣。缓存有界，不依赖区块生成次序。

参数比较使用相同三种子：最终48格网格在12.193km²中接受260条，21.324条/km²；逐种子21.90／22.39／19.68条/km²。统计按全地府面积计，不仅统计高崖群系。正式几何QA使用另一组完整样区，结果如下。

## 最终独立检查

三种子各4.460544km²，合计13.381632km²、275条，实测20.5506条/km²；逐种子95／98／82条（21.30／21.97／18.38条/km²）。不是每平方公里固定配额，沼泽与湖面等缺少高崖的位置不会强行放链。
