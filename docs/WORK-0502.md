## Fixes and failed candidates

1. `ManuscriptFlightMixin`: `WrapMethod` replaces the field-specific expression hook. Preserve the whole native method and temporarily clear manuscript-owned survival flight permission only for non-ordinary-fall sources, restoring it in `finally`. Same policy in modern ports. No permanent ability change or network update during the scoped call.
2. `EquipmentDurabilityMixin` (1.21.1): wrap stable `EnchantmentHelper.getItemDamage`, then call native Unbreaking with the filtered amount. Obtain the armor owner from the scoped pre-hit `ArmorProtectionContext`. NeoForge widens/splits the old `ItemStack.damage` target. A first scoped-owner/operation candidate transformed without errors but Connector silently removed `GearData.wearCost` from the call arguments (1024 requested wear became1024 actual wear). A second expression hook was remapped to an invalid descriptor. Both were discarded; actual wear assertions, not the Connector audit percentage, determine success.
3. `OuterNoiseSettingsMixin`: `WrapOperation` and `original.call` replace a constructor `Redirect + @Local`; the old combination caused `FactoryRedirectWrapper` to cast an annotation list to a single annotation while creating dimensions.
4. Native1.21.1 also failed world registry loading on newer imported resources. A build-output-only adapter preserves integer trapezoid probability weights, grass attempt counts, offsets and replacement predicates; adapts vegetation tag encoding and modern texture objects. A legacy-only feature implements predicate-configured `block_blob`. Missing later plants use the nearest old foliage. Shared modern assets, terrain parameters, ore policy and loot are unchanged. Stellar glass gets its missing legacy translucent render layer.
5. Release packaging now verifies the legacy JSON adapter output and explicitly rejects Connector QA classes/resources from public JARs.
