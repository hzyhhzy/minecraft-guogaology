# 当前玩法规则核对 · 0.3.11

[English](MERGE-REVIEW-CHECKLIST.en.md)

本表取代旧强化规则。最新职责与计算见[本轮记录](WORK-041.md)，强化数值可用[离线模拟器](enhancement-simulator.html)查看。

|项目|当前规则|
|---|---|
|世界分工|大数表界提供四档矿物与普通生物；里界和果糕地府提供晶核与巨构|
|装备|ω／ε／Γ／Ω四档镐、剑、护甲与手稿；数字石镐／剑是数字装备例外|
|数字镐采集等级|0～4石、5～7铁、8钻石、9下界合金；原属性渐进数值保留|
|手稿|无耐久，副手被动；右键直接镶嵌，绑定原件，四档2／3／4／6槽|
|强化|按各效果分别求和或平方和开根号；普通小额加算、深层增强；四件甲与手稿保护合并一次|
|耐久|紫菜凝核16／64／256倍求和，再加少量序数增强；仅降低消耗概率，所有维度一致|
|晶核分工|序列增产；分枝范围／挖速／头盔呼吸；紫菜耐久／治疗；九类都可装手稿|
|飞行与保命|空集Lv1跳高可与高阶共存，Lv3覆盖Lv2；深层冲刺水平及竖直八倍；果糕Lv2+消耗真实图腾|
|虚空与防护|声波和虚空吃保护；表界Y≤−1000进入里界，里界Y≤−120进入地府Y500|
|附魔|四档序数装备／手稿不可附魔，数字石工具及原版保留|
|前进门|主世界蛋糕＋苹果；表界十二矿物结晶块可混搭＋Ω材料；里界十二果糕＋果糕|
|返程门|十二个同款专用归途框＋一张归途签；框每次制作1个，签为木板在上／木棍在下|
|出口|有界异步准备，优先复用附近安全门、再建安全门，失败静默回退；仅靠近预热不造出口|
|空间比例|主世界:表界:里界:地府＝1:1:4:16|
|晶核显示|64格内动画，外侧普通区块内显示静态内核；Voxy保留静态远景|
|生物／Boss／进度|七类普通生物限表界；不加九头蛇生物、Boss或探索进度|
|旧存档|早期开发不做旧存档迁移|

配方、采集和操作见[生存指南](SURVIVAL-GUIDE.md)，移植范围见[移植说明](OUTER-IMPORT.md)。
