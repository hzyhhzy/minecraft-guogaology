# 方块采集表 · 0.3.1

本表与运行时共用 block_balance.json。工具栏为天然方块的加速工具，石／铁表示自然采集门槛。数字、颜色和彩灯分片随物品保留。碰撞体积不等于掉落物，本表单列掉落规则。

玩家放置的区域晶核、TREE三色节点、建筑专属稀有装饰、LHO五种材料及高阶序数晶体，徒手或任意工具均完整回收；LHO玩家放置物不触发消失或连锁。Lv1序数晶体徒手通常掉2～4晶屑，时运最多4，精准采集掉完整方块，爆炸按原版衰减。
