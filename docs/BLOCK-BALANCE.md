# 方块采集表 · 0.5.7

简体中文 | [English](BLOCK-BALANCE.en.md) · [生存指南](SURVIVAL-GUIDE.md)

主要方块配置与运行时共用 `block_balance.json`，果糕灯塑形台单独注册。工具栏表示加速工具，石／铁表示采集门槛。碰撞体积不等于掉落物，本表单列掉落规则。

全部区域晶核和序数晶核均可徒手或任意工具完整采集；显示Lv1/2/3固定100/200/400tick，在20TPS时为5/10/20秒，工具、附魔、状态和手稿都不改变进度。表内晶核硬度仅为保留的方块属性，不能用于推算固定采集时间。普通序数晶体硬度1.5对齐石头，镐正常加速，挖掘直接掉本体，包括徒手；四晶屑与一晶体可以在工作台双向转换，不再采用萤石式挖掘掉屑。TREE三色节点是普通材料，硬度1.5。

里界和地府野外不再摆放成品晶核或普通晶体。八种自然材料节点完整掉本身，镐更快；序数晶矿三种母岩外观共用晶屑产物，基础每矿4～6片，时运增产，精准采集掉矿石，硬度3且可徒手采集。0.5.6在全部岩体高度均匀放置小矿脉，按原版典型铁矿的实际岩体占比校准，LHO矿脉次数为其五分之一；没有额外外露剔除，具体实测见WORK-056。表界四档装备矿仍为硬度3／3.5／4／4.5，铁镐采集。

天然ψ／Z／fffZ／FOS仍需周围5×5×5普通序数晶体锚定或自身已稳定，八个角也在范围内；附近玩家手持晶体仍可提供稳定。范围内显现稳定配色，离开后恢复判断；触碰消失、树体连锁与玩家放置后永久稳定的机制保留。合成的空无晶核与野外碎片分开。

任意表情果糕灯普通挖掘统一掉该颜色完整张嘴基础款；精准采集保留实际表情与分块。果糕灯塑形台可一换一选择54种同色形态。数字彩灯与无字彩灯是另外的方块家族，掉落规则不变；数字砖和数字灯继续保留已编辑的数字。
