# 26.3 存档兼容审计：Alice 0.5.4.1 → 0.5.10

2026-10-17。审计对象为收到的原始26.3 JAR，而非仅凭版本号推断。原包SHA-256：`056f959d2fa0c60a7686075fe9b971b78655fb7bb9f64eaf4cec96bc5e17b18d`；原始改动作者为Alice (AliceLdl)。源码对照基线为已完成资源及算法还原核验的`69edcfd`，当前代码为0.5.10及本轮成就图标/排序修改。

本轮最终26.3候选包SHA-256：`42d227fa0fd12aba943ce2bef827e0f9baaeba761959c12ae41de27bf5d866d7`。用户明确仅需兼容这一旧版本；如果发现需要较大迁移工程的硬问题，先报告取舍，而非擅自加入迁移。

## 结论及边界

**静态审计预计支持直接升级，不需要因缺少旧注册ID而强制新建存档；但旧区域的资源分布、宝箱奖励和装备数值不会完全保持0.5.4.1体验。** 尚未拿实际26.3旧档副本进行加载、保存、退出后重进，不能把这份审计描述成已完成真实旧档迁移测试。没有启动26.3，没有改动任何正常存档或fo263_2，也没有加入自动迁移或清理程序。

## 需要注意的差异

1. **旧区块不会补矿，也不会自动把旧野外晶核替换成新原料。** 0.5.4.1里界/地府已生成区域仍保留当年的野外晶核和序数晶体；新增序数晶矿、矩阵薄片等材料主要需要去新生成区域取得。已开过很多地图的玩家可能要走较远。这是资源循环差异，不是“读档后矿石丢失”。表界ε新矿候选减半、Ω翻倍亦仅影响新生成部分。

2. **巨构不会整座翻新。** 旧区块中的陈列、晶核数量、终境巨树顶端奖励保留旧实物；新生成部分采用当前布景。横跨新旧区块的同一建筑可能混用两套陈列。主外壳/地形位置规则并未整体重排，不能据此声称建筑必然断裂，但布景和奖励不保证一致。

3. **未生成内容的旧宝箱会用新奖励。** 16个本地巨构主/副箱战利品表ID保留，内容已经降档并加入新原料。如果箱子的物品已经实际生成并存入NBT，则物品保留；如果仍只有LootTable/LootTableSeed，则首次开箱按当前表计算。主箱区域晶核由三级降为二级，序数晶核由显示二级降为显示一级。副箱也会改为原料和晶屑。

4. **旧装备会更新属性。** 规则版本48→49，物品inventoryTick/耐久路径会刷新装备，保留镶嵌与损耗比例。裸套护甲总值16/18/20/22改为15/20/24/30；韧性总值4/8/12/16改为0/8/12/16。这不是旧装备读错或丢失。存箱中的自定义属性可能直到物品被取出、参与相应刷新路径后才更新，展示不应作为永久旧数值保证。

5. **旧方块现在按新采集规则。** 等级晶核固定5/10/20秒；普通序数晶体完整掉落本体，矿物结晶块按对应矿石的硬度与采集要求；果糕灯普通掉落保留颜色/表情但清除分块，精准采集保留形态。这些改变对旧世界中已经摆放的方块同样生效。

6. **附魔与镶嵌互斥。** 普通0.5.4.1序数装备不允许附魔，常规旧装备不受这一点影响。若曾用指令或其他模组做出“既附魔又镶嵌”的特殊物品，物品和镶嵌列表会保留，但带原版附魔时晶核效果被禁用，需移除其中一套。这是目前明确的冲突处理，不会静默删除晶核。

7. **成就不追溯所有历史行为。** 原arrival键保留，但改为自动目录根；新增首次入界、材料/晶核、进入巨构等条件不会凭空知道过去的探索记录。入界成就可能要重新进一次维度，物品成就要再触发一次物品栏变化；群系/巨构检查会在实际到场时补上。原版进度定义未被覆盖。

8. **LHO可能出现短暂重新着色。** 新anchored字段不重写旧stable和player_placed，附近晶体存在时按5×5×5刷新。天然材料的原有消失/连锁机制仍存在，不能把新增颜色理解成所有旧天然材料自动永久稳定。密集旧LHO区的首次刷新存在额外运算，但当前实现限定已加载区块和每tick队列预算，不同步强制生成邻区块。

9. **新LHO建筑不再预先稳定陈列品。** 本轮追加删除该建筑的Astra辉光石，并使新生成的栏杆和内部天然材料遵循野外消失/连锁规则；玩家放置和序数晶体的范围保护保留。旧区域已保存的辉光石和stable状态不自动清除，不借此改写旧建筑。

## 不应混为一谈的情况

- 本报告只指Minecraft26.3→26.3的Mod升级；并不等于允许把26.3存档拿去26.2或1.21.1打开。
- **升级后再降回0.5.4.1不保证安全**：新原料、矿石、塑形台、展示图标等在旧包未注册。若要回退，应该恢复升级前的整份存档副本，而不是只换回旧JAR。
- Voxy远景是独立缓存。远处暂时保留旧画面不能直接判定方块NBT损坏；本次没有清理用户的缓存或更改Voxy配置。

若要把“预计可兼容”升级为实际确认，最小验证是在隔离目录复制一份真实0.5.4.1的26.3存档，用对应26.3新包检查三维度、背包及箱内镶嵌装备、旧门、LHO材料和旧巨构，再保存退出并重新进入；正常原档保持不动。本次尚未执行该步骤。
