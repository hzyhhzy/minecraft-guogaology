# 固定返程材料方案 · 0.3.9

用户希望返程容易，但不再随便摆当地石土后扔一块相同材料。用户已确认实施：保留十二块框架与 5×5 布局，增加用途明确、可以就地制作的归途框和统一的归途签。

| 所在世界 → 目的地 | 固定框架 | 一次制作 1 块框架的材料 |
|---|---|---|
| 表界 → 主世界 | 表界归途框 | 4 圆石＋1 任意木板 |
| 里界 → 表界 | 里界归途框 | 4 序数晶屑＋1 任意木板 |
| 地府 → 里界 | 冥林归途框 | 4 果糕冥土＋1 冥杉木板 |

每扇门制作十二次，得到十二块框架。三种框架不能互相混搭。归途签由上方1块任意木板与下方1根木棍制作一个；摆好门后投入一张，消耗后激活。框架和激活物都有明确用途，普通石土或原木本身不再被识别成返程门。

表界成本为48圆石＋13任意木板＋1木棍；里界为48晶屑＋13任意木板＋1木棍；地府为48冥土＋12冥杉木板＋1任意木板＋1木棍。不计玩家已有的工作台。里界与地府的一阶序数晶体可徒手取得晶屑，不需精准采集或完整晶体；地府冥土和冥杉木也可就地取得。返程不使用矿物、高阶晶核、苹果或必须提前携带的东西。

外观仍遵循目的地三套设计：去表界／主世界、去里界、去地府。自动生成的返程门继续可以直接使用。主世界蛋糕＋苹果的入门仪式，以及表界→里界和里界→地府的进阶仪式不在本方案内改变。

本方案已获用户确认，0.3.9实施。三种归途框有独立注册ID、专属低台座模型和徒手完整掉落；归途签为带返程纹样的木签。原C1空集修复与表界圣诞树材质一并保留，实施和验证见[WORK-039.md](WORK-039.md)。
