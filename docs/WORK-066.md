# 0.6.6 — 原生配方书整理与精准采集经验修复

基线`330dc06`（0.6.5）备份到`codex/backup-0.6.5-before-recipebook-xp`；工作分支`codex/0.6.6-recipebook-xp-fixes`。没有main合并、push或Release授权。

## 范围

- 「GGG」改为「果糕逻辑／Guogaology」，页签直接使用元数据中已有的Mod主Logo，不能新增仅为图标而注册的物品。
- 晶核配方集中在晶核页、其他Mod专属配方集中在果糕逻辑页，从四个原具体分类移除重复；原版全局Search继续搜索全部。通用木系留在原分类，Mod转换到原版TNT不能误删普通沙子＋火药的TNT配方。
- 查精准采集挖矿仍掉经验，覆盖原版附魔、分枝精准模式、普通／时运、额外开采和可能共用该路径的原版经验方块。保持实际工具附魔、镶嵌物、耐久机制和材料／硬度／LHO稳定规则。

## 配方书

「果糕逻辑／Guogaology」页签直接绘制`fabric.mod.json`所引用的`assets/guogaology/icon.png`，未新增图标物品。晶核页和品牌页的配方从四个原具体分类移出，Search仍保留所有配方；普通木系、普通沙子＋火药TNT不移动，核爆菇转TNT属于品牌页。

现代版本在原生分组阶段先按配方逐条分流，再生成原生RecipeCollection和搜索树，防止同group的普通配方被专属配方一起带走；旧版在对应原生集合中处理。可合成状态和实际配方查询仍来自服务器同步，不创建客户端假配方，不扩展配方网络枚举。重载、清空及重建时同步清理分类缓存。

四版成品检查同时要求相应Mixin配置、实际类、主Logo常量与资源存在。打包检查的最小测试夹具已补齐新入口，并保留缺配置／缺类／错Logo的负例检查。

## 经验漏洞根因与修复

原版真实精准采集在正常经验矿上已经正确不掉经验。问题来自分枝芽核的精准开关：旧`lootTool`只给物品掉落计算使用带Silk Touch的工具副本，原版后续经验回调仍拿到不附魔的实际工具。于是完整矿石和经验同时掉出；不仅四种序数矿，原版钻石等经验矿也会受影响。

现在包装原版六参数`Block.dropStacks/dropResources`入口，只在原本适用的分枝精准模式下，沿整个掉落流程传同一Silk副本。已有物品掉落处理继续工作，经验计算也能看到精准；实际持有的工具、数量、晶核、附魔和普通耐久损耗不被这次副本转换修改。普通及时运模式仍用原路径。额外开采走同一真实破坏流程，因此一并修复。

保持正确工具、LivingEntity来源和无方块实体等原适用条件。没有粗暴禁止所有「精准工具」的经验：刷怪笼即使真实精准采集，原版仍给15～43经验且不给物品；此例外保留。

兼容审查发现NeoForge21.1.248会把原版经验调用移到`CommonHooks → BlockDropsEvent`。因此不用依赖已被改写的具体指令位置，最终采用两种实现都保留的六参数入口。缓存字节码已确认同一工具参数进入`getExpDrop`和`processBlockExperience`，事件取消逻辑未绕过；没有新增NeoForge依赖或线程临时状态。本轮没有启动Connector，静态检查不能替代运行覆盖。

## 运行证据与边界

实际运行仅使用隐藏、不捕获鼠标的隔离fo262，不复制或修改正常存档。`Experience066Checks`让真实生存玩家调用`destroyBlock`，读取实际ItemEntity和经验球；经验球按`getValue × count`计算，避免合并经验球漏算。没有用只查loot表的结果代替完整破坏回调。

- 旧版对照：`build/runtime-qa/recipebook066-baseline-a`，加载准确的0.6.5成品（SHA见0.6.5记录），1546次主方块破坏、6540项断言通过并复现漏洞。重复放回Ω矿再用分枝精准挖8次，仍得到20经验。
- 初步0.6.6验证：`recipebook066-native-a`已通过，但其后为Connector调整了入口，因此不作为最终安装依据。
- 最终中文、英文：`recipebook066-final-zh`／`recipebook066-final-en`，使用下表同一最终26.2成品，均得到`RECIPEBOOK066_RUNTIME_OK`；每次1546次主方块破坏、6788项经验／物品断言、4009项GUI断言通过，重复精准回收经验为0。每次检查8种本Mod表界／地府矿、8种原版经验方块、5种零经验对照，覆盖普通、原版精准、原版时运III、分枝时运II、分枝精准；另含真实额外开采、不得向下开采、重复精准矿回收和刷怪笼例外。实际工具的晶核、附魔、数量在每次破坏后保持，仅允许正常耐久变化。

GUI检查涵盖28种晶核输出、专属页与旧具体页按实际display ID互斥、总条目守恒、全局搜索、普通木系及普通TNT保留、与专属配方同group的普通配方分流、可合成筛选、原生鼠标／悬停、320×240窄屏与2×2背包。Logo从实际加载资源取SHA，与元数据指定资产一致；背包截图等待12tick和异步截图完成。已核对最终中英晶核／品牌页、窄屏和背包原生截图，品牌页名称分别为果糕逻辑／Guogaology，Logo正确且页签无重叠。

不声称其他Minecraft版本、Connector、独立服务端或JEI四组合本轮运行通过。不改注册ID、存档格式、材料／战利品数量或fffZ/FOS/ψ/Z稳定规则；没有扫描和重写旧区块。原有兼容工程与0.6.4的真实旧档升级测试仍是此前证据。
