# 0.7.0 挖掘图案窗口输入审计

本轮只检查，不修改生产代码、版本、安装或发布。审计分支为
`codex/audit-0.7.0-pattern-window`，基线为 `46fd287`（真实 main）。

## 源码与原版字节码确认

26.3 改用 SDL 输入常量，现代共享 `EnhancementScreen` 的手绘模态页仍写死
旧 GLFW 数字；正常原版 Button 和容器页面则使用原生输入判断。

| 输入 | 26.2 原版值 | 26.3 原版值 | 模态页处理 |
| --- | ---: | ---: | --- |
| Esc | 256 | 41 | 只判断 256，26.3 Esc 被吞掉 |
| 左键 | 0 | 1 | 返回、清空、重置只判断 0；选格时把 1 当右键 |
| 右键 | 1 | 3 | 仅处理 0/1，26.3 右键无动作 |
| 背包键 | 可改绑 | 可改绑 | 模态页吞掉 Esc 以外的所有按键 |

具体源为 `ports/common/client/dev/guogaology/client/EnhancementScreen.java`：
`patternClick`（75–85 行）、`keyPressed`（128 行）。
`tools/prepare_port_sources.py` 对 26.3 的渲染接口转换没有转换这些输入数字。

因此实际左键会发送移动参考格的 200 系列按钮包，而不是切换连锁格的
100 系列包；Esc、背包键与正常左键返回均不能退出图案页。

服务端关闭容器、离开强化台有效距离或死亡仍走原版强制关闭路径，
不经过该自定义按键判断，不能将问题描述为整个客户端或服务器死锁。

## 旧验证的覆盖边界

`MiningPattern0612Visual` 直接发送开页按钮包；`MiningPattern0612Checks`
直接调用服务端菜单按钮。它们验证同步、图案、物品归属和服务器关闭，
没有验证客户端 Esc、返回区域和左右鼠标键。原生截图证明绘制正常，
不证明输入可用。

## 本轮运行时验证

使用新建隐藏、不可聚焦、不捕获鼠标的独立 26.3 客户端测试世界，
通过真实 `EnhancementScreen` 的鼠标和按键处理函数以及原版按钮包观察。
生产 JAR 必须为已发布 0.7.0，SHA-256：
`17bd1e1fbc631ebcbab29711d842d9083952d3e01be1baacf36cccab734248bf`。

运行入口：`tools/run_pattern_window_070_audit.py`，仅替换临时 QA JAR 的
入口；正常 fo263_2 只提供只读运行库、加载器和选择的模组，存档、账户与
设置既不复制也不修改。正常 fo262 不参与本轮。

原生运行已完成：`build/runtime-qa263/pattern-window070-263-a/`。
真实入口左键十次全部成功，无需发送备用开页包。十个操作用例的观察如下。

| 操作 | 实测结果 |
| --- | --- |
| 真实 Esc（41） | 编辑页保持开启，图案未变 |
| 默认背包键 E（8） | 编辑页保持开启，图案未变 |
| 真实左键点击返回 | 编辑页保持开启，图案未变 |
| 真实左键点击格 18 | 没有选中该格，而是把参考格从 12 改为 18 |
| 真实右键点击格 18 | 无动作，参考格仍为 12 |
| 注入旧 Esc 编号 256 | 成功返回强化主页，图案未变 |
| 注入旧左键编号 0 点击返回 | 成功返回强化主页，图案未变 |
| 注入旧左键编号 0 点击格 18 | 成功选中格 18，参考格仍为 12 |
| 注入旧右键编号 1 点击格 18 | 成功把参考格改为 18 |
| 服务端关闭容器 | 屏幕消失，回到正常玩家物品栏菜单 |

每例输入后等待 18 次客户端 tick，再由服务端队列独立采集状态。
每例仍恰好一把镐、一个镶嵌晶核、零个游离晶核；本次没有丢失或复制。
这是单机集成服务端的新建受控物品测试，不是所有联机或外部模组组合的认证。

`pattern-window070-results.json` 保留完整输入、客户端和服务端状态、物品
原版 codec、精确 JAR 哈希及三张原生截图。三张图片均人工查看：真实 Esc
和真实返回后仍在编辑页，旧编号对照后为强化主页。完成审计标记只表示
观测流程结束；五个真实用户操作失败，不能解释为无缺陷测试通过。

实际加载 Fabric API `0.161.0+26.3`、Sodium `0.9.2+mc26.3`。
正式生产 JAR 在测试前后哈希一致。正常 fo263_2 的 50 个模组及启动文件
哈希无变化；正常存档、账户、配置未读取或复制，fo262 未操作。

首次 Gradle 在受限环境中无法连接自己的回环 daemon；离线授权构建后成功，
只生成 QA 工具。运行时未修改生产 JAR。测试启动时的临时 simulationDistance
设置 3 被原版拒绝并回落默认值，未阻断流程；runner 已改为原版允许的 5，
没有因此重复这轮输入测试。
