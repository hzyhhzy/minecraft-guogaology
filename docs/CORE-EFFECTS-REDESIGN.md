# 晶核效果与手稿改版方案

2026-10-06。本文保留方案讨论过程。用户随后授权实施，最终改为序列增产、分枝开采／挖速、紫菜凝核耐久／回血；最新规则以 [WORK-041.md](WORK-041.md) 为准，下方早期职责表及待选状态不再作为当前规范。

后续选择已记录：用户认可上一轮整体方案，Laver、临界手稿、果糕装备三个备选组均选A。晶核职责重排仍是讨论方案，不能把下方建议的序列/Laver交换当作已确定。特殊维度冲刺飞行的最新确定规则是普通非冲刺创造飞行的水平和竖直速度均×8，覆盖旧四倍与44/87二选一。

普通维度指主世界、下界、末地、大数表界；特殊维度指大数里界和果糕地府。HP为生命值，2HP等于一颗心。下列平方和开根号只在明确要求时使用，范围格数向下取整；回血、生命、触距、伤害和速度保留小数，不暗中取整。

## 聚合公式与边界

等级记为l=1,2,3；挖速单颗值记为s=1,1.5,2。只把真正生效的主手装备、身穿护甲和副手手稿计入对应效果，背包中闲置物不参与。

| 效果 | 普通维度 | 特殊维度 |
|---|---|---|
| 镐额外格数N | floor(sqrt(sum(l²))) | sum(l²) |
| 手稿挖速倍率K | max(1,sqrt(sum(s²))) | max(1,sum(s²)) |
| 幂塔攻击加值A | sum(l)，包括武器和副手手稿 | 相同，特殊序数倍率另算 |
| 分枝耐久保护D | max(1,sum(16/64/256)) | 相同 |
| 分枝每4秒回血R | sqrt(sum(l²)) HP | 相同 |
| 空集触距加值T | sqrt(sum(l²)) 格 | 相同 |
| 临界爆炸系数E | sqrt(sum(c²))，c=0.15/0.225/0.30 | 相同，攻击基础的特殊序数倍率另算 |
| 果糕额外生命H | sqrt(sum((4l)²)) HP | sum(10l) HP |

例如两颗Lv2：普通额外挖2格、特殊8格；手稿挖速约2.121倍/4.5倍；耐久128倍；每4秒回血约2.828HP；触距约+2.828格；果糕生命约+11.314HP/40HP。

八颗Lv3放Ω镐为额外8格/72格，仍可采用现有9×9平面的80个候选位置。六颗Lv3放Ω手稿为4.899倍/24倍挖速，或每4秒7.348HP回血，或普通+29.394HP/特殊+180HP。有限槽位已经限制上限，不建议沿用旧版3HP治疗和20HP手稿生命上限，否则会截断新规则。

根号模式存在暂时没有增益的范围节点，例如两颗Lv1仍额外1格；第三颗也仍为1格，第四颗才是2格。GUI直接显示最终额外格数，不用笼统“点数”掩盖结果。回血、触距等不取整，仍会从第二颗起增加。

## 基础挖速和现有强化的含义

当前数字0～9镐基础挖速为4+5d/9，即4～9；ω/ε/Γ/Ω镐分别9/11/14/18。该值是原版破坏进度中的速度系数，不是每秒能挖几格；方块硬度、采集资格、20TPS、原版惩罚和效果仍影响实际时间。

按当前普通石头硬度1.5、正确工具、有采集资格、无其他修饰的简化计算，进度每刻约为速度/(30×1.5)：基础9需要5刻即0.25秒，18需要3刻即0.15秒，单格连续开采还有原版节奏。序数矿及其他方块不能直接套这个石头例子。新手稿倍率应作用于最终适用挖速，保留原版急迫、疲劳、水下和离地等规则；以后序数装备没有效率附魔，普通装备的已有附魔仍可生效。

现有攻击1点也不是攻击力+1。当前普通倍率M=1+3p/16，特殊M⁴，最多16点。以Ω剑基础16为例，从0点到1点变成普通19、特殊约31.82。用户新规则改成基础16+幂塔加值，例如一颗Lv3变19；武器Lv3加手稿Lv2则变21，序数晶体按新方案另外计算。

### 挖速Lv1待选

严格按1/1.5/2倍，单颗Lv1在任一维度都不会加速。两颗才是普通sqrt(2)倍、特殊2倍。此结果必须明确显示，不把“1倍”偷偷改成“+1倍”。

建议将单颗改为1.25/1.5/2倍，其他公式不变，让Lv1一颗就有25%提升；用户未选择前，以原定1/1.5/2记录。将其解释为+100%/+150%/+200%会把单颗实际值变成2/2.5/3，改动较大，不建议默认采用。

## 当前界限防护的详细解释

现有“1点防护”是强化预算，不是1点原版护甲或固定1%减伤。从0点加到1点，额外有效承伤能力在普通维度乘1.1875，特殊乘约1.98854；继续加点时应比较新旧M，不是反复乘这个固定数。

| 无晶核整套 | 当前减伤 | 20HP对应有效承伤量 |
|---|---:|---:|
| ω | 50% | 40HP |
| ε | 60% | 50HP |
| Γ | 66.67% | 60HP |
| Ω | 75% | 80HP |

头/胸/腿/脚份额为20%/40%/25%/15%。四件各装1点合计才是全身1点；手稿1点直接是全身1点。Ω套只给胸甲一颗界限Lv1时，普通减伤从75%变76.74%；四件各一颗或手稿一颗时变78.95%，有效承伤量80变95HP；特殊对应87.43%和约159.08HP。不是额外抵挡一次攻击，也没有可耗尽盾条。

旧果糕生命同样被算进防御预算，防止生命与减伤把同一份强化乘两遍。新规则若采用明确的额外生命、临时护盾等，不能把旧果糕预算再保留一次。

### 界限防护建议

建议改成直接展示“额外承伤倍率”，单颗Lv1/2/3全身贡献分别25%/50%/75%。设Q=sum(护甲部位份额×各颗l²)+sum(手稿各颗l²)，普通额外倍率F=1+0.25sqrt(Q)，特殊F=1+0.25Q；本系所有来源合并一次，再与该套基础减伤结合。

没有界限时F=1；手稿单颗Lv1/2/3分别F=1.25/1.5/1.75，意味着界限单独额外减伤20%/33.33%/42.86%。Ω套单颗手稿Lv1后总承伤倍率4×1.25=5，20HP可承受100HP原始伤害，最终总减伤80%。特殊单Lv3的F=3.25，Ω套最终92.31%减伤。

四件装同样配置时只算一次完整配置，不把四件倍率相乘。HP提升是独立可见资源；共同预算只防止同一核心在生命、防御中重复计入，不把用户指定的额外HP折扣掉。序数增益只增强晶核贡献的防护部分，不给原有基础防护重复乘算。

这一新界限公式是建议，用户只确定其用于防护，尚未确定具体等级、根号与深层系数。

## 手稿打开与附魔限制

手稿右键打开自身晶核菜单，左侧原物品与晶核槽，下侧背包，右侧按当前维度显示攻击加值、挖速倍率、范围、触距、回血、生命、耐久消耗概率和飞行方式。支持直接拖放、取回、Shift转移和背包可用晶核高亮。手稿不用台子、经验、能量或材料费，自身材料档位和槽位仍生效。

菜单期间锁定这一本手稿的真实物品位置，不能用交换副手、丢弃或换栏复制内容；退出后晶核仍存在原手稿内。只在副手提供被动效果，放主手打开不等于提供副手加成。镶嵌行为由服务端逐次验证。

禁止序数镐、剑、四件甲及手稿通过附魔台、铁砧附魔书、双装备合并等普通生存路径取得附魔。数字石工具与原版工具暂保留原规则。具体可替代生态位见后文；不要为了填满原版附魔列表，把弓、鱼竿、三叉戟专项硬塞进没有对应装备的晶核。

## 空集手稿的飞行规则

功能按装入的最高等级决定。最高为Lv2时无步行加速，混装Lv1也不改变Lv2的这一规则。建议最高为Lv3时同样不叠加Lv1步行加速，避免低级核心改变高档模式；Lv3这一边界仍列为建议。只有最高等级为Lv1时，多颗每颗+25%步行速度。

Lv1伤害倍率0.25作用于实际摔落伤害，不改变下落速度；与原版摔落保护等减伤相乘。Lv2/Lv3免正常摔落。实现按DamageTypes.FALL明确识别，不把末影珍珠自伤或钟乳石刺伤自动当作普通摔落。Lv3额外免鞘翅fly_into_wall伤害，不免窒息、挤压和虚空。

双击跳跃随时开启/关闭悬停，空格升、潜行降；卸下手稿只取消本Mod授予的权限，半空卸下时保护一次安全落地，不侵占创造或其他Mod飞行。Lv2建议按约3.6格/秒水平、2.5格/秒升降固定慢飞，不给予冲刺加速；重复核心不加速。相同飞行操控可在1.21.1使用，不依赖不存在的乐魂实体。

本地26.2原版代码在20TPS和默认属性下推算：创造普通水平约10.89格/秒，冲刺约21.78，升降约7.50；骑乐魂约3.61格/秒。均是代码推算，不是本轮游戏实测。

用户后续明确：特殊维度冲刺时，普通非冲刺创造飞行的水平与竖直速度均×8。默认20TPS代码推算，特殊冲刺水平约87.11格/秒，升降约60.00格/秒；特殊非冲刺仍约10.89/7.50。普通维度保持原版普通水平10.89、冲刺水平21.78、升降7.50。

水平×8是最终目标，不再额外叠加原版冲刺×2，避免错误变成174.22格/秒。竖直必须单独随特殊冲刺加速，不能只改水平飞速；停止冲刺、离开特殊维度或卸下手稿时恢复对应速度。上述是设计目标与代码推算，尚未运行实现。

无需给每类装备强塞果糕。下列各自能够单独采用，推荐先选一条；手稿的生命与免疫按已定规则独立保留。

| 方案 | 适用装备 | 效果建议 | 登场空间 |
|---|---|---|---|
| A 展开束缚，推荐 | 剑 | 命中给予缓慢I/II/III；Lv2加虚弱I，Lv3加虚弱II。状态等级取最高级，持续时间min(8,3×sqrt(sum(l²))/max(l))秒：单颗各等级都是3秒，同级两颗约4.24秒 | 与幂塔直接伤害、临界范围伤害分工；追击、撤退、近战压制有用，不给同类攻击力重复标签。Boss状态免疫仍有效 |
| B 果糕护盾 | 护甲 | 一套同配置Lv1/2/3临时护盾为4/8/12HP，多颗及部位份额平方聚合；连续8秒未受伤时恢复。受伤时先消耗，不增加最大生命 | 区别于手稿永久生命与分枝持续治疗，适合建筑探索和间歇战斗。四件共用一条盾池，不每件独立触发；不能靠换装立即回满 |
| C 诡异反噬 | 护甲 | 被敌人近战攻击后反伤1/2/3HP，按部位和核心平方聚合，每0.5秒至多一次 | 填荆棘生态位，适合被围攻；不响应环境伤害和其他反伤，不相互递归。若选临界手稿B，此项不再同时加入 |

果糕无需再承担护甲最大生命，避免和手稿同一功能重复。A的“展开”与诡异记号主题相符，B保留外壳/内核的保护主题。

## 序数晶体万能增益建议

不再使用旧“点数塞进所有主属性M”的规则。每颗Lv1/2/3/4贡献万能量u=0.06/0.12/0.25/0.50；普通U=sqrt(sum(u²))，特殊U=sum(u)。相同属性所适用的装备和副手来源合并一次，闲置物不计入。护甲的全身生命/防护贡献使用与界限相同的部位份额；手稿贡献只加入一次，不能分给四件后又算四次。

### 普通维度

| 属性 | 序数增量 |
|---|---|
| 挖速 | 在序列的最终挖速倍率上+U；没有序列时为1+U |
| 攻击 | 在基础攻击和幂塔加值之后+2U HP |
| 触距 | 在空集触距增量之后+0.5U格 |
| 每4秒治疗 | 在分枝治疗之后+0.5U HP |
| 最大生命 | 在果糕额外生命之后+4U HP |
| 防护 | 在界限额外承伤倍率上+0.25U；与基础甲结合一次 |
| 耐久 | 在分枝保护倍率上+16U；没有分枝时先取基础1 |

镶嵌在镐只影响这把镐的挖速、触距和耐久；剑只影响这把剑的攻击、触距和耐久；护甲只影响生命、防护和自身耐久；手稿的对应被动增量作用于玩家及实际使用的装备。单个序数晶体不会替玩家凭空解锁飞行、状态免疫、范围爆炸或精准采集。

普通手稿六槽例子：六颗序列Lv3为sqrt(6×2²)=4.899倍；五颗序列Lv3加一颗序数Lv4为sqrt(5×2²)+0.5=4.972倍，还带+1攻击、+0.25格触距、+2HP生命、少量治疗、防护和耐久。因此在这个场合一颗最高序数比第六颗专核更划算，但单序数Lv4挖速1.5倍仍低于序列Lv3的2倍，不代替所有专核。

### 特殊维度

序数倍率G=1+2U。挖速采用K×G；攻击应区分基础与幂塔增量，采用B×(1+0.25U)+A×G，其中B为装备基础攻击、A为武器和手稿的幂塔总加值。这样没有专核时仍有小幅增益，专核贡献受到更明显放大；避免把高基础攻击也整个乘G，导致全序数替代幂塔。果糕额外生命和界限防护增量采用G；不把基础生命20、基础甲防护再乘一遍，也不解锁能力类功能。没有果糕/界限专核时保留序数本身的小幅生命/防护加值，不把零贡献直接乘成零。范围挖掘不由序数放大，避免把单次破坏数量扩展成数百格。

空集触距、分枝回血和耐久用户明确所有维度一样，因此三项不应用特殊G：它们都用U_fixed=sqrt(sum(u²))，触距T=sqrt(sum(l²))+0.5U_fixed，回血R=sqrt(sum(l²))+0.5U_fixed，耐久D=max(1,sum(d))+16U_fixed。没有对应专核时其根号和为0。此处是“序数特殊直接相加”与“三项全维度一致”的例外建议，应单独确认；另一选项是让专核基础保持一致，但混装序数后的最终效果允许分维度。

特殊手稿六槽的挖速例子：六序列Lv3为24倍；五序列Lv3加一序数Lv4为20×2=40倍；四序列Lv3加两序数Lv4为16×3=48倍；六颗序数Lv4单独仅为1×7=7倍。挖速上混合比全专核强，而全万能没有赢过专核；高阶万能的材料成本也能获得回报。普通的固定小加值与特殊G不同时再加一次。

特殊攻击例子，主手无晶核Ω剑基础16：六颗幂塔Lv3手稿为16+18=34；六颗序数Lv4手稿为16×1.75=28；三颗幂塔Lv3+三颗序数Lv4手稿为16×1.375+9×4=58。混合明显更强，全万能不替代幂塔。不能把挖速的混合优势直接泛化为所有属性，攻击用这一独立数例验证。

临界剑的爆炸系数E不再乘G：剑的强化攻击值已经包含一次G，爆炸用该攻击值×E，避免单个序数因同时增强剑值和系数变成G²。手稿投射物爆裂若采用，也遵守每次伤害只计一次序数倍率。范围仍只由序列专核触发，候选9×9维持足够；触距没有空集时只有序数的小幅加值。

此组u和G是可计算的建议，不是用户已经确认的具体数值。旧的耐久D=(1+2p)²及主属性上限16点不应与新方案叠加，否则重复计数。

## 原版附魔生态位

本地26.2原版数据共43种附魔，包含新武器专项；本Mod现有手持序数装备只有剑和镐，不需要复制弓、弩、三叉戟、鱼竿、重锤、长矛的所有专项。

| 生态位 | 对应晶核或方案 |
|---|---|
| 锋利、通用攻击增强 | 幂塔；序数少量补充 |
| 效率 | 序列手稿；序数少量补充 |
| 耐久、经验修补的续航需求 | 分枝装备，序数手稿；以低耗代替自动修复，允许基础修理 |
| 保护、火焰/爆炸/弹射物保护的泛用防护 | 界限，伤害范围另行明确，不提供全伤害免疫 |
| 摔落保护与移动探索 | 空集手稿 |
| 横扫之刃、范围输出 | 临界剑；含主目标，但不毁地形 |
| 时运、抢夺 | 推荐Laver A |
| 精准采集 | 可将其作为Laver A中菜单切换的副模式；若不选此附加，保留原版精准工具的独立用途 |
| 水下呼吸、水下速掘、深海探索者 | Laver B备选；不建议仅为列表完整把这些叠进A |
| 荆棘 | 果糕C备选 |
| 击退 | 临界手稿C备选，不作为无限可堆主属性 |
| 冰霜行者、灵魂疾行、迅捷潜行 | 空集的飞行/步行覆盖部分需求，不必强加每项 |
| 火焰附加、亡灵/节肢专项 | 暂不强制替代；果糕A提供控制而非同类专伤 |
| 诅咒和其他武器专项 | 不添加对应晶核功能 |

精准采集若作为Laver A的副模式，GUI中明确选择“增产/完整采集”，两种不同时生效；精准不是每一等级都新增数值。其材料等级带来的主要递进仍在增产效力，避免Lv2/Lv3只有模式名字升级。

## 晶核职责重排建议

推荐只交换序列与Laver整套职责，保持已选功能及聚合公式，不同时加入未选B/C方案。该交换尚待用户决定。

| 晶核 | 装备 | 手稿 | 主题对应 |
|---|---|---|---|
| 序列 | 镐增产/时运、剑增产/抢夺 | 当前主手增产 | 序列展开、列数增多，对应产物增多 |
| Laver | 镐范围处理，原序列的额外格数算法 | 挖速，原序列的挖速算法 | iBLP表格迭代、成片处理，对应作用范围与处理效率 |
| 分枝 | 镐/剑/护甲耐久保护 | 治疗 | 生长、延续和恢复 |
| 幂塔 | 剑攻击加值 | 攻击加值 | 增长强度 |
| 空集 | 镐/剑触距 | 飞行与摔落防护 | 跨越空间与虚空 |
| 临界 | 剑范围爆炸 | 投射物爆裂 | 爆发与冲击 |
| 界限 | 护甲防护 | 全身防护 | 边界与屏障 |
| 果糕 | 剑束缚控制 | 生命、状态免疫，图腾保留项另列 | 混乱展开及抵御异常 |
| 序数 | 当前装备多项小加成 | 多项小加成及特殊维度混合倍率 | 通用强化 |

单看增产意象，分枝最具象；但将增产给分枝会挤走当前耐久/治疗，并迫使别的核心接收关联较弱的效果。两组交换既保留分枝生长主题，也让序列与Laver各自围绕同一个职责。
