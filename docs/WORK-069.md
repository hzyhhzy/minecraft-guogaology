# 0.6.9：综合审计确定问题修复

2026-10-20。根据用户最新授权，修复0.6.8审计的六类确定问题，保留旧存档；主要实测26.3，并回归26.2。未获main合并、push或Release授权。

审计快照：`4c6a0f5`，分支`codex/audit-0.6.8-general`；生产基线为发布0.6.8的`c122ac5`。本轮开发分支`codex/0.6.9-audit-fixes`。原始失败与调查仍见`docs/AUDIT-068-GENERAL.md`，不改写历史证据。

## 修复

1. 仅26.3的核爆额外伤害适配改用`LivingEntity.damageCooldownTime`。剑／弓都保留原计时器及`lastHurt`的`finally`恢复，不再清除`Entity`真正的临时无敌字段；其他三个目标保持其原生正确字段。
2. 紫菜船增加中英实体名称，物品名称不变；语言审计同时解析普通及有限循环注册实体，避免遗漏同类动态键。
3. 机柜、终端、椅子、震惊瘫坐椅、蛇头支持按玩家方向放置、原版旋转与镜像。前两种新增水平`facing`，默认north，north模型与原无属性模型完全相同。后三种原有状态定义、四向模型及碰撞形状不变。
4. 四版补紫菜原木／木块的原版斧头去皮映射，保留三个轴向。冥杉及两木系其他原版行为不改。
5. 仅1.21.1：船摔毁时使用自身木板；仍调用原版落地判据、规则与三木板两木棍数量，不复制一套摔落算法。临时上下文标志由`finally`恢复，不写入NBT。
6. 仅1.21.1：放置船时调用原版`createDefaultStackConfig`，应用物品名称及原版允许的实体数据。旧船ID、类型、变体及保存格式不改。过去已经丢失且未存入实体的名字无法凭空恢复；不承诺回收船保留完整实体NBT。

未实现审计中尚未证实的超容量组件、断线重连请求等加固建议。未调整配方、掉落数量、数值、生成或原LHO稳定机制。
