| 命令 | 约定用途 |
| --- | --- |
| `/googology`、`/googology help` | 简明帮助及可点击命令入口 |
| `/googology tp outer` | 固定前往表界 |
| `/googology tp inner` | 固定前往里界 |
| `/googology tp underworld` | 固定前往地府 |
| `/googology tp overworld` | 固定前往主世界 |
| `/googology up` | 返回上一层：地府→里界→表界→主世界 |
| `/googology kit portal <outer\|inner\|underworld>` | 领取指定前进门所需的完整框架与激活材料 |
| `/googology kit return` | 领取当前层12块归途框及1张归途签 |

`tp` 已在目标维度时只提示，不反向切换；`up` 不表示床、出生点或上次坐标。仅整理玩家命令，不改变正常传送门的双向规则。当前源码仍是 `visit/inner/guogao/return/kit`；改名时需要同步四版入口、帮助与双语指南。
