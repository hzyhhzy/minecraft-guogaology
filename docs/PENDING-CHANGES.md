### 0.5.0 · 命令整理（已完成）

本轮已实现以下命令方案。根命令统一为 `/guogaology`；帮助所有玩家可看，传送和材料包仍要求管理员权限（等级2）。四版构建与隐藏fo262命令回归已通过，证据见 [WORK-050.md](WORK-050.md)。

| 命令 | 约定用途 |
| --- | --- |
| `/guogaology`、`/guogaology help` | 简明帮助及可点击命令入口 |
| `/guogaology tp outer` | 固定前往表界 |
| `/guogaology tp inner` | 固定前往里界 |
| `/guogaology tp underworld` | 固定前往地府 |
| `/guogaology tp overworld` | 固定前往主世界 |
| `/guogaology up` | 返回上一层：地府→里界→表界→主世界 |
| `/guogaology kit portal <outer\|inner\|underworld>` | 领取指定前进门所需的完整框架与激活材料 |
| `/guogaology kit return` | 领取当前层12块归途框及1张归途签 |

`tp` 已在目标维度时只提示，不反向切换；`up` 不表示床、出生点或上次坐标。仅整理玩家命令，不改变正常传送门的双向规则。本轮同步四版入口、帮助与双语指南，替换原有 `visit/inner/guogao/return/kit` 命令组织。
