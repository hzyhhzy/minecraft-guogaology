# 0.5.5 equipment enchantment policy

- Numeric picks/swords and all four ordinal picks/swords/armor/bows can take meaningful native enchantments. Gear has enchantability 15; bows retain vanilla's 1. Every material tier has the proper native data categories, including modern melee-weapon and bow categories. Manuscripts have no artificial vanilla enchantment category or enchantability.
- Native enchantments and socket contents are mutually exclusive on an individual item. Any occupied socket, including a manuscript Totem, blocks enchanting. All native enchantments, including curses, block installing socket contents. Removing the final socket content restores enchanting; removing all enchantments restores sockets.
- The same rule controls actual enhancement-slot insertion, shift-click routing, inventory highlights, API installation, native table eligibility, enchantment selection/direct application and anvil output. Armor/material repair and renaming retain existing core-preservation checks. Two-item repairs cannot consume an unseen second core inventory.
- Equipment refresh never silently removes enchantments. Grindstone removes regular enchantments using vanilla behavior and leaves curses intact. Command/other-mod-created mixed components retain their items, but all crystal effects and socketed-Totem activation are suppressed while native enchantments exist. The profile cache includes enchantment presence; removing enchantments immediately restores the stored core profile.
- Native bow ammunition processing and spawned-projectile effects are honored, so Infinity and Flame work on un-socketed ordinal bows. Legacy arrows already apply the spawn hook in their constructor; modern arrows apply it after successful spawning, once.
- Manuscript deferred activation and real-item ownership/death handling are unchanged. Suppressed contents remain removable and are never copied into drops from effect snapshots.

Validation: `tools/tests/test_equipment_enchanting.py` checks all native category coverage and generated resource roundtrips. `ports/qa26/dev/guogaology/mergeqa/Core055EnchantChecks.java` exercises actual native table predicates, enchant operations, anvil/grindstone results, station clicks, malformed-component suppression and Infinity/Flame release in the isolated fo262 runtime.
