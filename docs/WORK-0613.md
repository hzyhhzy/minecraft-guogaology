# 0.6.13：弓与塑形台外观修正

2026-10-25。用户要求修正序数弓拉弓时的物品图案并检查玩家动作、移除物品说明的“潜行挖掘：关闭范围开采”，以及修正果糕灯塑形台右侧模具的非正方形和叠面闪烁。

前置版本为0.6.12提交c760b34，备份分支codex/backup-0.6.12-before-visual-repairs；开发分支codex/0.6.13-visual-repairs。用户随后明确授权本轮验证后合并到本地main，仍不push、不发Release。保留存档ID、装备数值、配方和0.6.12挖掘图案。用户追加的灯带和地府基岩另开0.6.14分支，不混入本次合并；fo262将在后续候选验证完成并关闭游戏后一起更新，fo263_2不替换。

## 修正范围

- 弓贴图的原拉弓端点不对称，箭尾逐帧移动偏离弓身中轴；修正图案，保留各矿物的颜色和原版弓显示变换。
- 原生第一人称用原版弓物品ID判断是否隐藏另一只手；增加只识别正在使用的序数弓的客户端包装，继续由原版选择手部显隐。第三人称和拉弓的摇动／拉伸本来就沿用BOW动画，未重写。
- 删除中英物品提示及其退役文案键；潜行跳过连锁的机制和强化台操作说明保留。
- 塑形台左模具平面为6×6、右模具为5×6；统一正方形比例。清理模型相互接触和穿插部件的内部面，保留原台体风格、材质和游戏逻辑。
