# 统一里外公式与收窄手稿通用效果

后续深层攻击／防护逐级标定已由[WORK-045.md](WORK-045.md)覆盖；本页倍率及峰值保留作revision44历史记录。

2026-10-06。用户先要求空手稿及手稿上的序数晶体不增加挖速倍率、耐久、触距或最大生命，回血改为乘在晶核项上；随后确认所有效果都沿用表界的加算／平方求和开根号，里界只改变单颗数值。仅更新离线模拟器、晶核说明和数值审计。主Mod仍0.3.11，没有更改生产Java、资源、四版适配或安装包，也没有运行游戏、安装、提交或推送。

## 已定规则

- 生效手稿仍优先副手，副手无手稿时才读主手，不叠加两份书。
- 手稿固有b和书内序数只参与攻击、防护、已有紫菜治疗的增强，不影响挖速倍率、工具或甲耐久、触距、生命。序列手稿的专用效率II／IV／VI、分枝手稿的专用触距保留。
- 工具自身序数仍提供挖速、耐久与触距；护甲序数提供自身耐久与加权防护。不能因为删除手稿项而误删装备项。
- 最大生命仅为 `20+4*sqrt(sum(bookGuogaoLevel²))`，所有维度一致，任何序数晶体、护甲或手稿b都不加生命。
- 每4秒治疗为 `sqrt(sum(bookLaverLevel²))*(1+0.5*(sqrt(sum(bookOrdinalU²))+b))`。沿用原0.5系数作乘算；没有紫菜核时为0，所有维度相同。普通食物自然回血另算，虚空预测未额外假定它。
- 里外所有效果都使用同一聚合方式。序列额外开采为单颗量的平方求和开根号后向下取整；单颗量普通1／2／3、深层1／4／9。最高8槽分别8／25个额外方块，另加本次主方块。
- 攻击统一 `B+A+2U_attack`，A直接合并剑与书中幂塔的单颗攻击值，U为工具和书的序数攻击值RSS+b。不再对基础攻击或幂塔总攻击另乘深层因子。
- 挖速统一 `(BaseMining+EfficiencyBonus)*(1+U_pick)`。U只取镐自身序数，序列书效率依然加e²+1；水下／未站稳惩罚保留。
- 剑爆裂和书投射物爆裂都为攻击值乘相应单颗系数的RSS。书不再额外乘序数或b，剑系数里外相同，避免重复放大强化攻击。

## 统一防护

`F=F0*(1+0.25P)*(1+0.25Udef)`，最终伤害除以F。

P是界限单颗防护贡献的加权RSS，Udef是序数单颗防护贡献的加权RSS+b。四甲权重仍头0.20／胸0.40／腿0.25／靴0.15，书完整计入。F0为四甲基础防护合并一次，不乘四个单件因子。两个环境形式完全相同，没有有核／无核分段；增加任意界限核到空槽时，其他项不变，P增大，F必定增大。

## 本轮暂定量级

为保留深层较强、普通环境较温和的定位，以下系数按新的共同公式重新标定。它们是本轮设计选择，用户只确认了公式统一，未逐项指定这些倍率；审计页明确列出供核对。

| 深层单颗贡献 | 相对普通 |
| --- | ---: |
| 幂塔攻击 | 8倍 |
| 序数攻击u | 32倍 |
| 镐序数挖速u | 8倍 |
| 界限防护贡献 | 16倍 |
| 序数防护u | 8倍 |
| 手稿投射物爆裂系数 | 4倍 |

倍率先作用在单颗对应字段，再按共同公式聚合。b不放大。治疗、生命、触距、耐久、时运／抢夺、效率、水域和隐蔽数值维持里外一致；飞行仍保留之前确定的深层冲刺水平与垂直8倍。禁止将某个序数倍率全局套入所有属性。

最高深层裸攻击使用13颗幂塔III加1颗序数IV，共362HP；首颗序数IV能比同槽幂塔III提高攻击，但更多序数的RSS边际递减。治疗最优为5紫菜III+1序数IV，共11.7394HP/4秒，比6紫菜III的11.0227稍高，保留综合核混搭价值。
