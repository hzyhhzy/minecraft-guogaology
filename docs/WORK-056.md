# 0.5.6 — 序数晶矿分布修正

2026-10-16～17 用户报告全新里界也难以找到序数晶矿，随后明确要求：不要照搬原版铁矿高度分布，改为典型铁矿的平均密度；LHO 序数晶矿密度为其他群系的五分之一，矿石提高透明度以融入周围玻璃。

基线为 `05f1288` / `codex/0.5.5-core-resources`，独立开发分支 `codex/0.5.6-crystal-ore-distribution`。不改装备数值、表界四种矿、晶核功能或既有采集配方；不做旧区块回填。无 main 合并、push 或 Release 授权。

## 实施清单

- [x] 删除 upper/middle/small 三组绝对高度分布，整个可用岩层高度采用均匀的原版小矿脉。
- [x] 用原版 26.2 实际生成铁矿/可成矿岩体比例校准平均密度；分别报告里界、地府、LHO 的真实样本，不能只用候选次数冒充密度。
- [x] LHO 单独降低矿脉次数至五分之一，不影响其他群系，不在边界叠加两份特征。
- [x] 空境序数晶矿继承空境玻璃底材，晶纹使用更透明的浅色；检查近景和静态远景资源。
- [x] 八种新自然原料降低精致感：五种完整方块，薄片/芽穗/膜保留简朴外形，外观与碰撞一致。
- [x] 恢复上一轮撤掉的巨构陈列装置，保留原装饰密度与造型，只更换其材料；真实本系晶核仍为5～10颗，箱子奖励及其他既有修正不回滚。
- [x] 更新中英生存指南及方块说明，保留 0.5.5 的历史测试事实。
- [x] 适用纯检查、四版构建、隐藏 fo262 新世界生成/画面验证。
- [x] 用户明确仍只更新 fo262；确认该实例关闭后，备份旧包并安装。正在运行的 fo263_2 保持原样，其他模组、正常存档和配置不变。

## 原因与验证边界

0.5.5 用铁矿的 Y−24～56、底部～72、Y80～384 三组绝对高度。此前实测证明部分区域确实成矿，但不能证明每种浮空岩层都易于找到矿；本轮以岩体内平均比例和垂直分布重新验证。普通石头不是序数晶矿的成矿母岩，实际母岩仍为十种数字刻石、空境玻璃、果糕冥岩。

完整逐类审计见 [INTERIOR-AUDIT-056.md](INTERIOR-AUDIT-056.md)。所有普通装饰的成品核占位都改为指定主题材料；只有专门珍藏装置和四张演奏桌保留晶核。对每一种待转换的模型名称使用明确规则，未审计的新模型若含晶核占位会抛出离线构建检查错误，不默认随机替换。

## 本轮测试进度

62项Python检查、资源/中英文本/移植资源审计通过。内饰蓝图14,240项断言、28个宝箱8,192种变换下123,044项通路检查通过；16种奖励表160,000次抽样不改变0.5.5奖励。

首轮完整新世界实测 `ore-056-c`（原候选50/10）通过全部七个里界群系与地府真实成矿、两个原生截图检查。原版64区块基准共1,847,691块可成矿岩石、5,186块铁矿，即2.80675块/千岩石；普通里界样本3.32277块/千岩石，故调到40次候选，以靠近基准。LHO首个16区块样本偏高，最终测试扩大为8片相隔区域，避免以小样本直接宣布五分之一已经达标。

### 最终生成与外观结果

最终参数：普通群系每区块40次候选，LHO每区块8次，都是 `minecraft:ore`、脉大小9、从维度底部到顶部的均匀分布，无外露放弃。每个群系只登记适合自身的一份特征，不会叠加普通/LHO两份。

隐藏fo262 `ore-056-d` 使用种子560516、全新正常世界、正式候选包、Fabric API、Sodium及Voxy；只在独立目录操作，没有读取或改写正常存档。共采样304个不同区块，其中原版64、非LHO里界六群系各16、LHO八片相隔区域共128、地府16。样区按有岩体选择，绝不按是否富矿选择；薄浮岛不以“岩层必须很厚”排除。

非LHO里界为该原版样本的94.39%，LHO为普通里界的22.61%；配置候选比严格为20%，实际矿脉块数有空间随机波动。地府小样本高17.1%，仍属铁矿平均密度量级。不同群系岩体体积悬殊，因此这些是**每岩体密度**，不是各群系每平方公里矿块数相等，也不是对所有种子的全局平均保证。

32格垂直分带核验通过：所有有足够岩石的总体高度带均有实际矿石；花园和紫菜上层浮空岩体在Y224以上也有矿。原生截图 `screenshots/ore056-0.png` 的八材料/三矿、`ore056-1.png` 的玻璃墙与透明矿均已逐张查看。原矿晶纹不再是实心白斑，背景可透过，普通模型无紫黑材质。最终标记为 `ORE056_NATIVE_GENERATION_OK chunks=304` / `ORE056_RUNTIME_OK`，明细在 `build/runtime-qa/ore-056-d/ore056-density.json`。

此前两次夹具验证分别发现采样器排除了过薄LHO岛，以及旧纸带桌加宽后容不下原位置；前者只修正QA的有岩体选样规则，后者用转角端帽保留原桌宽。均已在后续测试覆盖，失败记录未冒充成功或安装到正常游戏。
