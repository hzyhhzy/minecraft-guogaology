# 0.3.11：晶核效果、手稿与强化模拟器

2026-10-06。用户已授权实现，完成后按长期授权安装；不包含 GitHub 发布。普通环境为主世界、下界、末地与表界，深层环境为里界和地府。HP 为生命值，2 HP 等于一颗心。本文覆盖早期效果草稿。

## 最终职责

| 晶核 | 装备 | 副手手稿 |
|---|---|---|
| 序列晶核 | 镐增产／剑额外掉落 | 与工具增产等级直接相加 |
| 幂塔晶核 | 剑攻击 +1 / 2 / 3 | 同样攻击加值，与剑相加 |
| 分枝芽核 | 镐额外开采；头盔水下呼吸 | 挖掘速度 |
| 空集晶核 | 触及距离 | 跳跃、摔落保护、分级飞行 |
| 紫菜凝核 | 耐久保护 | 治疗；Lv2+ 夜视 |
| 临界核晶 | 剑命中爆裂 | 投射物命中爆裂；Lv2+ 防火 |
| 界限晶核 | 护甲保护 | 同一保护预算 |
| 果糕之心 | 剑减速／虚弱 | 生命、状态免疫、调用真实图腾 |
| 序数晶体 | 多项少量增强 | 多项少量增强，深层放大专属加值 |

所有九类都能装入手稿。四阶手稿保持 2 / 3 / 4 / 6 槽与原阶级限制，不消耗耐久；右键直接存取晶核，副手持有才有被动效果。两手都有手稿时，优先编辑副手手稿；不叠加两本。四档序数装备不可附魔；数字石工具和原版工具不在此限制内。

## 计算规则

- 增产：工具与手稿的序列等级直接求和，不互乘；不复制完整晶核、容器内容或玩家摆放物，沿用真实采集条件。
- 范围开采：分枝等级平方求和，普通开根号再取整，深层直接使用平方和；潜行关闭，遵守采集与安全边界。
- 挖速：手稿单颗分枝 Lv1 / 2 / 3 为 1 / 1.5 / 2 倍；普通平方求和开根号，深层平方求和，无核心时为 1。保留原版挖速、急迫等机制。
- 攻击：幂塔等级求和，剑与手稿共同计算，不对四件装备反复乘算。
- 紫菜耐久：各颗 16 / 64 / 256 直接求和，消耗概率为倒数；所有环境一致，不增加容量、不修复损耗。
- 紫菜治疗：每 4 秒恢复 `sqrt(sum(level²))` HP，所有环境一致。
- 空集触距：`sqrt(sum(level²))` 格，所有环境一致。
- 空集手稿 Lv1：摔落伤害乘 0.25，重复不叠；每颗跳跃增加 1 格，与 Lv2 / Lv3 共存。Lv2 免摔落，乐魂量级慢速飞行。Lv3 免摔落与撞击，创造式飞行，覆盖 Lv2。深层冲刺水平和竖直均为普通非冲刺创造飞行的 8 倍。
- 临界爆裂：单颗系数 15% / 22.5% / 30%，多颗平方求和开根号，半径 3 格，包含命中目标，不破坏地形；同次命中不递归触发。
- 界限保护：四甲份额 0.2 / 0.4 / 0.25 / 0.15，`Q=sum(份额×等级²)+sum(手稿等级²)`。普通容量因子 `1+0.25sqrt(Q)`，深层 `1+0.25Q`。整套裸装容量 2 / 2.5 / 3 / 4，合并后只应用一次，覆盖攻击、火焰、摔落、监守者声波与虚空。
- 果糕生命：普通 `sqrt(sum((4×等级)²))` HP，深层 `sum(10×等级)` HP。Lv2 免毒、饥饿、反胃、虚弱、缓慢；Lv3 加免凋零、失明、黑暗。Lv2+ 致命伤可消耗背包中的真实不死图腾。
- 果糕剑：缓慢 I / II / III，Lv2 虚弱 I、Lv3 虚弱 II；单颗 3 秒，多颗延长，上限 8 秒。
- 分枝头盔：最高 Lv1 / 2 氧气消耗速度为 1/4、1/16；Lv3 不消耗氧气。
- 序数：单颗通用值 `u=0.06/0.12/0.25/0.5`，普通 `U=sqrt(sum(u²))`、深层 `U=sum(u)`，深层专属增强因子 `G=1+2U`。普通把少量增强直接加到专属效果；深层放大专属增量，不重复放大基础生命和基础防御。触距、治疗、耐久以普通聚合保持全环境一致。
