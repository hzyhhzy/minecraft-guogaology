# Survival guide advancements · 0.5.11

The directory root completes automatically. First entering each realm explains its gate; return gates credit their activator. First Ω ore/mineral precedes Inner in the guide without locking travel. Vanilla progress and recipe unlocks remain.

Eight branches start with the seven Inner biomes and the Underworld dimension. Each has representative materials → core Lv1 → Lv2 → Lv3, plus a separate megastructure visit. Core titles reflect their capabilities; possession alone does not activate them. Entering the actual built space counts without opening a chest. Eating Guogao, playing a Laver table and a fully socketed 38-slot Ω loadout are additional milestones. Parents guide rather than enforce order; no extra items are awarded.
