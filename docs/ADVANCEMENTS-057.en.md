# Survival guide advancements · 0.5.7

The Mod tab appears on joining. These milestones use native advancements, keep vanilla progress and recipe unlocks, impose no required order and award no extra items. Gates credit the player who successfully offered the activation item. Megastructures count when their actual main or secondary reward chest generates loot.

| ID | Title | Guidance and condition |
|---|---|---|
| `arrival` | The Unfolding Begins | Begin with cake and an apple, then explore the Outer, Inner and Guogao Underworld. |
| `guide/portal_outer` | The First Gate | Activate a horizontal 5×5 ring of 12 cakes, without corners, by throwing an apple inside. |
| `guide/enter_outer` | Into the Outer Realm | Enter Outer Guogaology to mine and gather supplies for the next realm. |
| `guide/first_ore` | The First Ordinal Mineral | Obtain an ordinal mineral with an iron or better pickaxe. All four ores drop usable materials directly. |
| `guide/first_tool` | An Ordinal in Hand | Craft or obtain an ordinal pickaxe, sword or bow. |
| `guide/first_book` | A Manuscript to Carry | Craft a Denxi Manuscript. While it is in your offhand, use the Book button in your inventory to edit it. |
| `guide/full_set` | Ready to Wear | Obtain a helmet, chestplate, leggings and boots; the four ordinal materials may be mixed. |
| `guide/number_tools` | Tools from Numbers | Craft a Number Stone pickaxe or sword. Its digit is the floor of the material digits’ average. |
| `guide/return_ready` | A Way Back | Obtain a Return Token and frames. Activate a ring of 12 matching Return Frames with the token to return one realm. |
| `guide/portal_return` | A Return Gate | Throw a Return Token to activate a return gate. |
| `guide/return_home` | Home Again | Return from the Outer realm to the Overworld. |
| `guide/return_up` | One Realm Up | Return from Inner to Outer, or from the Guogao Underworld to Inner. |
| `guide/portal_inner` | A Mineral Gate | Activate a horizontal ring of 12 mineral blocks, freely mixing ω, ε, Γ and Ω, with one Ω mineral. |
| `guide/enter_inner` | Into the Inner Realm | Enter Inner Guogaology. Craft cores from biome resources and mine Ordinal Crystal Ore for crystals. |
| `guide/raw_material` | Biome Ingredients | Collect a core ingredient from a natural landmark. Finished cores do not spawn in the wilderness. |
| `guide/shards` | Crystal from the Rock | Mine Ordinal Crystal Ore for shards. Hands work; pickaxes are faster. |
| `guide/crystal` | A Stable Crystal | Craft an Ordinal Crystal from four shards, or unpack it again. A placed crystal stabilizes nearby LHO materials. |
| `guide/first_core` | The First Core | Obtain a core. Regional cores combine biome ingredients; Ordinal Cores fuse from Ordinal Crystals. |
| `guide/station` | The Enhancement Table | Craft an Enhancement Table to insert or recover cores. Enchantments and sockets are mutually exclusive. |
| `guide/socketed` | A Core Installed | Close an equipment or manuscript editor with a core installed. |
| `guide/higher_station` | Advanced Enhancement | Craft an Advanced Enhancement Table for second-grade cores. |
| `guide/ultimate_station` | Ultimate Enhancement | Craft an Ultimate Enhancement Table for third-grade cores. |
| `guide/core2` | Second-Grade Fusion | Combine eight first-grade regional cores with one first-grade Ordinal Core into a second-grade core. |
| `guide/core3` | Third-Grade Fusion | Combine eight second-grade regional cores with one second-grade Ordinal Core into a third-grade core. |
| `guide/ordinal3` | Condensed Ordinals | Fuse crystals and Ordinal Cores nine-to-one until reaching an Ordinal Core Lv3; every step is reversible. |
| `guide/lamp_shaper` | Shaping Expressions | Craft a Guogao Lamp Shaper to choose expressions, whole lamps and 3×3×3 exterior tiles. |
| `guide/compute_setup` | A Computing Setup | Collect Compute Chips and craft a server rack or terminal. |
| `guide/portal_underworld` | A Guogao Gate | In Inner, activate a horizontal ring of 12 Guogao blocks by throwing one more Guogao block inside. |
| `guide/enter_underworld` | The Guogao Underworld | Enter the Guogao Underworld and explore its forest, misaligned strata, silent mire and descending caverns. |
| `guide/landmark_first` | Into a Megastructure | Open a reward chest in any megastructure, then explore its floors and themed exhibits. |
| `guide/landmark_matrix` | Explore Matrix Folded Keep | Open a main or secondary reward chest in the Matrix Folded Keep. |
| `guide/landmark_power` | Explore Iterated Timber Pagoda | Open a main or secondary reward chest in the Iterated Timber Pagoda. |
| `guide/landmark_hydra` | Explore Six-Branch Crown Court | Open a main or secondary reward chest in the Six-Branch Crown Court. |
| `guide/landmark_absence` | Explore Missing-Page Galleries | Open a main or secondary reward chest in the Missing-Page Galleries. |
| `guide/landmark_weaver` | Explore Laver Triangle Palace | Open a main or secondary reward chest in the Laver Triangle Palace. |
| `guide/landmark_astra` | Explore Astra Inference Nexus | Open a main or secondary reward chest in the Astra Inference Nexus. |
| `guide/landmark_frontier` | Explore Boundary Calculus Court | Open a main or secondary reward chest in the Boundary Calculus Court. |
| `guide/landmark_guogao` | Explore Guogao Finality Tree | Open a main or secondary reward chest in the Guogao Finality Tree. |
| `guide/landmarks_all` | All Eight Megastructures | Explore all eight megastructure types and open at least one reward chest in each. |
