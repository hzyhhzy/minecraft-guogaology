# 生存与材料指南 · 0.3.2

简体中文 | [English](SURVIVAL-GUIDE.en.md)

果糕逻辑（Guogaology）包含两维度、八群系、八座代表建筑，以及矿业、扽西装备和晶核强化。当前没有自定义生物或 Boss，建筑中的战斗场地为后续内容预留。

## 前往大数世界

用 12 个完整蛋糕或任意颜色果糕围成 5×5 去掉四角的框，中间留空 3×3，两种材料可以混用。投掷苹果开启主世界与大数世界之间的门，投掷果糕方块开启通向果糕地府的门；在地府使用果糕门返回大数世界。破坏门框时整座门失效。

水平距离为主世界 : 大数世界 : 果糕地府 = 1 : 4 : 16。从大数世界落到 Y≤−120，会进入地府 Y=500。地府重力为四分之一，无摔落伤害。首次抵达未生成区域需要实际区块生成时间。

`/googology` 可查看帮助。返程通常使用传送门；`/googology return` 是管理员命令，需要相应权限。

## 采集与普通材料

| 材料 | 来源 | 用途 |
|---|---|---|
| 序数晶屑 | 徒手或任意工具开采 Lv1 序数晶体；建筑宝箱 | 四枚合成 Lv1 晶体，亦可从一枚 Lv1 拆回四枚；参与纹样和高级矿材加工 |
| 果糕切片 | 一块果糕拆成四片 | 食物 |
| 紫菜薄片 | 一块巨型紫菜叶拆成四片 | 合成紫菜桌板 |
| 算力芯片 | 机柜、终端在工作台各拆成两枚；建筑宝箱 | 合成证界合晶 |

Lv1 序数晶体采用萤石式掉落：通常 2～4 晶屑，时运提高产出但最多 4 枚，精准采集掉完整方块，爆炸按原版方式衰减。挖机柜和终端仍掉方块，只有放进工作台才拆解。

ω树原木、紫菜叶脉和幂塔铭木有木材相关配方；冥杉原木、针叶防火。数字砖、数列彩灯和果糕拼灯保留物品中的外观状态，搬走重放不会重新抽颜色或图案。

玩家放置的区域晶核、TREE 三色节点、建筑珍藏、LHO 五种稀有材料和高阶序数晶体，用任意工具或徒手都可完整回收；Lv1 序数晶体仍遵循晶屑规则。天然方块的工具要求见[采集表](BLOCK-BALANCE.md)。

## 六阶矿物与装备

矿物依次为 ω、ε₀、Γ₀、ψ、层峦、证界。在数字刻石及果糕冥岩中生成，两种母岩各有一套矿石；直接掉材料或矿屑，不经过熔炉。生成修改只影响新生成区块。

实际矿石数量受矿脉候选次数、地形、重叠与暴露筛选影响。外露矿候选保留 10%，洞壁候选保留 50%，埋藏候选全部保留。矿洞包含大小洞室和细长通道，部分通向露天地表或山体侧壁。

前四阶直接获得晶材；层峦和证界需要加工，工作台排列见配方书：

| 产物 | 每份材料 |
|---|---|
| 层峦晶材 | 4 层峦矿屑 + 2 序数晶屑 + 2 Y 序列山石 + 1 Lv1 序列晶核 |
| 证界合晶 | 4 证界矿屑 + 2 算力芯片 + 2 证明纹岩 |
| 证界晶材 | 4 证界合晶 + 4 序数晶屑 + 1 Lv1 界限晶核 |

每阶晶材可制作扽西镐、扽西剑及序数头盔、胸甲、护腿、靴子，也可九合一压成晶材块并拆回。数字刻石是非序数装备的入口：三个数字石合成数字扽西镐或剑，等级为三个数字均值向下取整，0～9 级保存在物品中，没有数字盔甲。

普通挖掘速度与序数矿专用的**扽西速度**分开。数字工具普通属性从石质升至下界合金水平；序数工具普通属性温和提升。序数矿使用独立硬度，低阶工具仍可开采，但可能极慢。数字 0 镐基础扽西速度与钻石镐相同；数字 9 镐约 5 秒开采 ω 矿。有效镶嵌等级使序数矿开采加速，这一指数增长不会直接用于普通石头。

## 强化台

装备放入左上格，直接向开放槽位放入或取出晶核，支持 Shift 转移。合格晶核在玩家物品栏高亮，右侧显示属性与**强化点**。强化点不是最终伤害、范围格数或经验百分比。

| 强化台 | 区域晶核 | 序数晶体 |
|---|---|---|
| 普通 | Lv1 | Lv1～2 |
| 高级 | Lv1～2 | Lv1～3 |
| 终极 | Lv1～3 | Lv1～4 |

装备也限制最高等级：ω/ε₀ 允许一阶，Γ₀/ψ 允许二阶，层峦/证界允许三阶。六阶装备分别有 2、4、4、6、6、10 槽，数字工具 1 槽；以装备与台子的较低上限为准。

| 晶核 | 适用装备 | 作用 |
|---|---|---|
| 序列晶核 | 镐 | 范围开采；潜行时只挖一格 |
| 幂塔晶核 | 剑 | 增加攻击力 |
| 分枝芽核 | 镐、剑、护甲 | 增加耐久容量 |
| 空集晶核 | 镐、剑 | 增加触及距离 |
| Laver 原核 | 镐、剑 | 提高获得的经验 |
| 临界核晶 | 剑 | 对附近目标产生爆炸溅射，不炸毁地形 |
| 界限晶核 | 护甲 | 增加序数防御 |
| 果糕之心 | 护甲 | 增加生命上限 |
| 序数晶体 | 镐、剑、护甲 | 强化装备主属性 |

同类晶核效果相加。区域 Lv1/2/3 分别贡献 1/1.5/2 强化点；序数 Lv1/2/3/4 分别贡献 0.5/1/1.5/2 点。扽西速度另用有效等级：区域晶核贡献其等级，序数晶体贡献等级减一，相加后每级使序数矿专用速度乘 4。

序数盔甲无镶嵌也有额外减伤，四件防御先相加再计算，覆盖攻击、摔落、火焰和熔岩，不免疫虚空。拆装保留耐久损耗比例；装备耐久耗尽时，晶核完整掉出。

## 晶核融合与拆分

八群系主晶核各有 Lv1～3，序数晶体额外有 Lv4。工作台九格无序合成：

| 产物 | 材料 |
|---|---|
| 序列／分枝／Laver／临界／界限／果糕 Lv2 | 8 本系 Lv1 + 1 Lv2 序数晶体 |
| 幂塔 Lv2 | 5 幂塔 Lv1 + 红、绿、蓝 TREE 节点各 1 + 1 Lv2 序数晶体 |
| 空集 Lv2 | 空集、fffZ、FOS 各 2 + ψ 枝、Z 枝各 1 + 1 Lv2 序数晶体 |
| 八系任意 Lv3 | 8 本系 Lv2 + 1 Lv3 序数晶体 |
| 序数晶体 Lv2/3/4 | 9 个前一阶序数晶体 |

序数晶体可逐级拆回九份前阶，Lv1 可拆回四晶屑；区域晶核没有拆回低阶配方。天然景物以 Lv1 为主，果糕终境巨树最终厅另有八种 Lv2 藏品。高阶 Laver 原核不替代演奏桌 Lv1 原核，高阶界限晶核不替代纸带端点。

## 景物交互

紫菜桌按现场图案识别，必须有 Laver 原核；不依赖种子，空位静音，不完整图案也可安全演奏。右键开始或停止。LHO 天然空集、fffZ、FOS、ψ/Z 枝需序数晶体锚定：副手携带或附近两圈（5×5×5）放置晶体；玩家重新放置后永久稳定。

图灵机纸带内置程序 #14263231。右键切换内容，红石上升沿启动；六面邻居中恰好两格为纸带或 Lv1 界限晶核才有效，允许直角和竖直转弯。核心仅作端点、不读写；断带、分叉、核心或未加载邻居使运行停止，纸带不会自动延伸。
