# Guogaology development

- User terminology (2026-10-05): the authorized reference `googology-dimension-1.0.0.jar` is called "alice版" / "Alice version". Comparisons to our pre-merge version use 0.3.2 (`bec510e`), not the merged 0.3.3 which already uses some Alice textures.

- Standing install authorization (2026-10-05): after completing changes and applicable validation, install the main Mod into the user's normal `fo262` instance by default without another confirmation. If Minecraft is running, defer installation and do not close the game. Check processes first, back up the previous JAR, then verify installed SHA-256 and exactly one main Mod. Leave add-ons, other mods, saves and configuration alone. This does not authorize GitHub publishing.

- 0.3.3 merger preview: `codex/0.3.3-outer-inner-worlds`, baseline `bec510e` backed up separately. Passive offhand Denxi Manuscript has no focus/charge/quota mechanics. Four accessible outer-world ore tiers replace the old six-tier exponential mining gate. Ordinary imported mobs spawn in the outer world only; exclude Hydra creatures and bosses, retain Hydra plants. Outer terrain/templates retain donor parameters through maintainable source/API adapters; see `docs/OUTER-IMPORT.md`. 1.21.1 includes an independently remapped source bridge inside the host JAR, not the donor archive.
- Three-layer portals: preserve Overworld cake + apple. Outer→inner requires twelve mineral storage blocks, freely mixing ω/ε/Γ/Ω, and one Ω mineral offering. Inner→underworld uses twelve Guogao blocks plus one Guogao offering. Return frames/offerings: Outer dirt or cobblestone, Inner numbered stone or absence glass, Underworld Guogao loam or rock. Return must never depend on rare cores/minerals or carried apples. Scale 1:1:4:16. Do not restore the active manuscript/energy proposal or old ore gates.

- Current release: 0.3.5. Chinese name 果糕逻辑; English name Guogaology. Early development: user explicitly does not require old-save migration. Commands and unrelated host IDs remain unchanged.
- 0.3.5 namespace: all runtime registries and assets/data, including entities, biomes, worldgen and templates, use `googology`. The retired `googology_outer` namespace must not appear in any release JAR, including the 1.21.1 bridge. Outer dimension/type/noise settings use `outer`, preserving the Inner `googology` definitions. `outer_generated_resources.json` is an exact ownership manifest: never clear the host namespace to regenerate imported data. Java package `dev.googology.outer` remains a source module, not a Minecraft namespace. No old-save migration.
- 0.3.5 art/names: equipment is ω镐/ε剑/Γ胸甲/Ω靴子, without 石. Epsilon ore/storage/mineral textures show ε₀, but names remain ε. Four Denxi Manuscripts have distinct dedicated pixel-art icons. Empty-set Lv1 uses the old broken cage and one inscription face; Lv2/3 keep their motion/shape with the same original ghostly material palette. Three portal designs differ clearly by color and motif; portal plane/outline is y=4.5..5.5 model pixels, lowered 0.25 block from 0.3.4. See `docs/WORK-035.md`.
- 0.3.5 Voxy: all 28 core/crystal meshes expose a cached static body through vanilla `getQuads` / `collectParts`, while nearby Fabric emission keeps only the fixed shell and the existing animated renderer. Omit outer orbiting decorations (part >= 10) in LOD. Voxy ignores vertex colors: regenerate the single padded tint atlas with `tools/generate_core_lod.py` after changing core art. Draw the static interior before its translucent shell because the installed Voxy software baker writes depth for translucent faces. Never restore empty vanilla quad lists, patch installed Voxy, or add Voxy as a required dependency. Hidden fo262 QA can load the installed Voxy using `run_merge_qa.py --voxy`.
- Shared materials: `tools/outer_content_ids.json` and `import_outer_content.ALIASES` are the mapping source; synchronize Java mappings with `unify_outer_content.py`. Alice stone families use vanilla counterparts, Christmas logs oak/dark oak, Laver uses the shared Alice-style log/plank/leaf family, and 空境玻璃 uses the host absence-glass block. Portal STYLE 0/1/2 follows the actual destination (surface/home, inner, underworld), including return trips. Matrix number bricks cycle 0–15 and colored numeral lamps cycle 0–32 on right-click; blank lamps become 0 and numbered stone does not change. Drops retain the edited state.
