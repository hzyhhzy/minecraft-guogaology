# 果糕逻辑 · Guogaology

简体中文 | [English](README.en.md)

![Guogaology](docs/branding/guogaology-mark.png)

**v0.7.0 · Minecraft Java / Fabric** · [下载与发行说明](https://github.com/hzyhhzy/minecraft-guogaology/releases/tag/v0.7.0)

本版从合并后的真实`main`主分支发布，汇总自v0.6.11以来，0.6.12～0.6.16已完成的更新；0.7.0本身只做版本重建，不另加玩法或数值。详见[本版发行说明](docs/RELEASE-0.7.0.md)。

- **自定义连锁挖掘**：在强化台选择竖直5×5图案和参考格；矩阵晶核单颗额外预算为1／2／4，表里一致，额度变化自动恢复对应默认图案。
- **弓与塑形台修复**：修正拉弓图案、箭的移动和第一人称手部显隐；塑形台右模具方正并清理叠面。
- **树灯与地府底座**：自然树灯带连续且留出间距；新地府区块补齐五层随机基岩和母岩连接。
- **原生行为修复**：晶核精准正确处理陶罐、冰与蜂巢中的蜜蜂；两木系机关补齐原版形态属性及标签。
- **精简装备说明**：能力摘要、已用／总槽位、每行两颗晶核；长摘要自动换行，详细数值留在强化台。
- **1000种iBLP**：保留1～69行的完整代表图案；1070条BMS和四种固定宫殿图案不变。

战斗数值沿用[0.6.11方案](docs/RELEASE-0.6.11.md)，此前的JEI、世界加载、传送门、配方书和晶核兼容修复继续保留；fffZ／FOS、ψ／Z稳定机制不变。[强化模拟器](docs/enhancement-simulator.html) · [当前生存指南](docs/SURVIVAL-GUIDE.md)

感谢@8266等人帮忙测试

三个相连的世界：接近原版尺度的大数表界、巨大记号景观与遗迹构成的大数里界，以及阴森的果糕地府。表界提供四档装备矿物和七类普通生物；里界与地府提供群系原料和序数晶矿，用于合成晶核。可逆强化台强化装备，副手手稿可通过背包「手稿」按钮镶嵌，关闭界面后生效。暂无 Boss。

表界的地形、模板与矿物装备美术来自获授权的 Googology Dimension 1.0.0（Alice版），移植来源和改动边界见[合并说明](docs/OUTER-IMPORT.md)。[当前生存指南](docs/SURVIVAL-GUIDE.md)

**0.5.4.1 的原始修改由 Alice（AliceLdl）完成。** 本仓库从其提供的 JAR 还原可维护源码并适配四个 Minecraft 版本；原始修改与移植工作分别记录，见[贡献者](AUTHORS.md)和[0.5.4.1 来源与验证](docs/WORK-0541-IMPORT.md)。

## 当前资源获取

- 里界与地府野外不再直接摆放成品晶核或序数晶体。采集矩阵薄片、幂塔铭木、SCG结点、Hydra芽穗、紫菜薄片、核爆晶块、集合膜与馃槹，搭配主题材料合成本系晶核；一级将普通序数晶体放在中央，二级／三级将ε／Γ结晶块放在中央，外围为八颗本系前阶晶核。巨构保留少量珍藏与低阶箱子奖励。
- 序数晶矿以原版铁矿的平均密度为基准，分别适应数字母岩、空境玻璃和冥岩。矿石掉晶屑，四晶屑与一序数晶体可以双向转换；晶体方块挖下直接掉本身。
- LHO 保留消失、连锁和稳定采集规则。序数晶体稳定周围两圈，ψ、Z、fffZ和FOS会显现稳定配色；空无晶核改由合成获得。
- 果糕灯塑形台在同一颜色内进行54种形态的一换一加工。普通开采统一掉完整基础灯，精准采集保留表情与分块。
- 序数及数字装备可选择原版附魔或晶核镶嵌，两条路线互斥；拆空晶核或去除全部附魔后可以换路线。战斗参数见[0.6.11发行说明](docs/RELEASE-0.6.11.md)，其余采集和手稿功能保留。

## 进入维度

用十二个方块围成末地门形状（5×5 去四角，中间空 3×3）：

| 所在世界 | 门框／投掷材料 | 目的地 |
|---|---|---|
| 主世界 | 完整蛋糕框（可混果糕）＋苹果 | 大数表界 |
| 表界 | 12个ω／ε／Γ／Ω结晶块，可混搭＋1份Ω序数结晶 | 大数里界 |
| 里界 | 12个任意颜色果糕方块＋1个果糕方块 | 果糕地府 |
| 表界／里界／地府 | 12个对应归途框＋1张归途签 | 返回上一层 |

表界归途框用4圆石＋1任意木板、里界归途框用4序数晶屑＋1任意木板、冥林归途框用4果糕冥土＋1冥杉木板；各一次得到1块。制作十二次摆成十二格门框，投入一张归途签（1任意木板在上、1木棍在下制作）激活。三种框架不能混搭；材料均可在当地取得。序数晶矿可徒手采集晶屑，普通序数晶体也能在工作台拆成四片。正常到达会生成可直接使用的反向门，破坏框架会使整门失效。

主世界、表界、里界、地府水平比例为 1:1:4:16。表界落至 Y≤−500 会进入里界，途中仍受可被防护减免的虚空伤害；里界坠入虚空会进入地府；地府重力为四分之一且无摔落伤害。

所有玩家可用 `/guogaology` 或 `/guogaology help` 查看帮助。以下命令要求管理员权限（等级2）：

- `/guogaology tp <outer|inner|underworld|overworld>`：固定前往表界、里界、地府或主世界；已在目标维度时只提示。
- `/guogaology up`：返回上一层，地府→里界→表界→主世界；不表示上次位置、床或出生点。
- `/guogaology kit portal <outer|inner|underworld>`：领取通往指定维度的前进门框架与激活材料。
- `/guogaology kit return`：领取当前层的12块归途框与1张归途签。

## 构建

需要 JDK 21、JDK 25、Python 3.10+；普通构建只使用 Python 标准库。Gradle Wrapper 已包含，首次构建会下载依赖。

```powershell
$env:JAVA21_HOME = '你的 JDK 21 路径'
$env:JAVA25_HOME = '你的 JDK 25 路径'
./build-all.ps1
```

产物、版本清单与 SHA-256 写入 `build/releases/0.7.0/`。也可以逐版构建，详见[构建说明](docs/BUILDING.md)。源码中的模型、材质和记号数据已经齐备，不依赖原作者电脑上的表格或历史文件。

0.7.0的内容与验证边界见[发行说明](docs/RELEASE-0.7.0.md)；功能实测沿用其中链接的0.6.12～0.6.16工作记录。[v0.6.9 Release](https://github.com/hzyhhzy/minecraft-guogaology/releases/tag/v0.6.9)及其[历史验证记录](docs/WORK-069.md)仍可查阅；旧版测试结果不代表本版重新测试过相同环境。

此仓库不包含临时晶核展厅、飞行调速工具、开发存档、缓存和历史备选设计。当前资源经过引用检查，检查器在 CI 中继续运行。[资源清理记录](docs/RESOURCE-CLEANUP.json) · [验证记录](docs/VALIDATION.md)
